# Erich Assuncao — Portfolio

Professional portfolio showcasing production software delivery, information
systems, data analysis, automated testing, and applied graduate research.

## Local development

```bash
npm install
npm run dev
```

The site runs on the vinext starter and produces Cloudflare
Worker-compatible output for Sites hosting.

## Validation

```bash
npm run build
npm test
```

The production build is written to `dist/`.
